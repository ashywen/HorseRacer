# HorseRacer

A TypeRacer-inspired multiplayer typing game — but the words don't just get typed, they *race*.

Built as the term project for **CS 2212: Introduction to Software Engineering** (2nd Year).

## 🏇 The Concept

Forget plain progress bars. In HorseRacer, your typing speed drives an actual horse race — the faster and more accurately you type, the faster your horse gallops toward the finish line. Miss a keystroke, and watch your horse fall behind.

## ⚡ Features

- **3 Difficulty Levels** that shift dynamically based on the time of day — the challenge changes depending on when you play
- **Multiplayer racing** — go head-to-head against friends in real time
- **Java + JavaFX** front end for smooth, responsive game rendering
- **Object-oriented architecture** across game logic, UI rendering, and input handling

## 🛠️ Built With

- **Language:** Java
- **UI Framework:** JavaFX
- **Build Tool:** Maven

## 🏁 Why HorseRacer?

This project was built over a 16-week, 10-sprint development cycle by a 5-person team practicing full agile workflows — sprint planning, daily stand-ups, and retrospectives — with a rotating Scrum Master role. Beyond the code, it was an exercise in translating a simple mechanic (typing speed) into something visual, competitive, and genuinely fun to watch unfold.

## 🚀 Getting Started

1. Create an account (Parental/Teacher or Student)
2. Sign in

## 🎮 How to Play

1. Join or start a race
2. Type the prompted text as fast and accurately as you can
3. Watch your horse gallop in real time based on your WPM
4. First horse to cross the finish line wins 🏆
